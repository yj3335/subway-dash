# Join Key Map

This file is generated by `python -m processing.profile_data` after raw datasets are present.

## Expected Defaults

| Dataset | Purpose | Expected Column |
|---|---|---|
| `data/raw/stops.txt` | GTFS static stop key | `stop_id` |
| `data/raw/MTA_Stations.csv` | GTFS stop key | `GTFS Stop ID` |
| `data/raw/MTA_Stations.csv` | Station complex key | `Complex ID` or `Station Complex ID` |
| `data/raw/MTA_Hourly_Ridership.csv` | Station complex key | `station_complex_id` |
| `data/raw/MTA_Hourly_Ridership.csv` | Timestamp | `transit_timestamp` |
| `data/raw/MTA_Hourly_Ridership.csv` | Entry count | `ridership` or `entries` |
| `data/raw/noaa_weather.csv` | Daily weather key | `DATE` |

## Conventions

- GTFS-Realtime stop IDs such as `127N` and `127S` are normalized to base stop ID `127`.
- Spark `dayofweek()` is used in batch outputs: Sunday = 1, Wednesday = 4, Saturday = 7.
- NOAA historical weather is daily and joins to ridership on `date` only.
- Local paths under `data/` are defaults; scripts expose CLI overrides for Docker or S3 paths.
